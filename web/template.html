How to use this laboratory / provenance / guarantees

Use → / ← to move between meaningful operations, Shift+→ / Shift+← for individual executed lines, R to reset, or Space to play. A+ changes the code font. The heap-array view shows actual storage order; the priority-order view is a separate sorted explanation. Ties use FIFO tickets issued on each insertion or strict priority improvement.

Traces are recorded from the shipped Python functions by tools/trace_search.py using sys.settrace. No second search algorithm runs in this browser. The highlighted line has executed; the visible state is its result. Internal heap operations are atomic here. Numbers printed on edges are costs, not pixel lengths. Main-graph h comes from the coordinates in graphs/main_graph.py; the grid uses four-neighbor moves of cost 1 and Manhattan distance to its target. Dark cells are blocked; S and T mark the start and target. Show h displays each cell’s heuristic.

An expansion processes outgoing edges and excludes the terminal goal extraction. A*'s expanded nodes may reopen; they are not automatically finalized. Stale entries are obsolete queue records, a different phenomenon. The overestimate and permanently closed examples intentionally remove optimality guarantees. Animation playback rate is NOT runtime; use results/comparison.csv for measured instrumented search times.

The separate closing-demo application is not part of this package. All content here works from a local file without a server.
